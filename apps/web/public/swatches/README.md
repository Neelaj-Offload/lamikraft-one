# Fixture swatches (illustrative)

These four wood swatches are **procedural, not photographs**. They are generated by
`apps/web/scripts/gen-swatches.py` (Pillow, deterministic seeds) and stand in for product media until
catalogue media lands in Slice 2. They map to the demo world's fixture decors:

| File | Decor no. | Decor name |
|---|---|---|
| `oak.webp` | 0120 | Natural Oak |
| `maple.webp` | 0310 | Hard Maple |
| `ash.webp` | 0415 | White Ash |
| `walnut.webp` | 0457 | American Walnut |

Each species has an albedo (`<name>.webp`, 1024 px), a tangent-space normal map
(`<name>-normal.webp`) derived from the same height field, and a 160 px thumbnail.
The mapping from a product to its swatch lives in `src/features/material-viewer/swatches.ts`; when real
renditions exist, change that file only. Every screen that shows a swatch labels it
"Material preview — not a product photo".
